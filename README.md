## 使用

vf.0.4.15 将悬浮面板分为“功能 / 个性化”两栏。功能包括玩模组、战斗检查、战场生成和开团流程；个性化包括DNJ、经验只分玩家队伍、适当美化和场景小巧思。保留拖动、生成期间锁定、失败撤回和更新入口，支持键盘左右键切栏及小屏滚动。

三项新开关控制配套浮士德预设中的独立提示：房规排除协力NPC分经验，名称美化用少量彩色中文与上方英文，原“秋青子小巧思”收窄为实际查看菜单、任务单、悬赏、账单、信件等载体时偶尔显示一张卡片。房规及名称美化默认关闭，小巧思保留原开启状态。它们影响后续AI提示，不追改经验或历史消息，不新增自动奖励结算器。

**组件在线更新不导入预设。** 已装vf.0.4.10更新器可在线安装刷新；手动只换悬浮脚本。随后导入本地交付的【DND】浮士德预设v1.0并选用，或保留个人预设、按固定ID合并三条提示。缺少条目或仍是旧小巧思时，新开关会禁用并提示适配。其他预设不读写；现有世界书和人物数据保持。

完整预设只留本地。公开局部正文在 `src/prompts/玩家队伍经验房规.txt`、`适当美化.txt`、`场景小巧思.txt`；前两条ID分别是 `dnd-house-party-xp-v01`、`dnd-style-names-v01`，放在原小巧思之前并加入prompt_order（默认关闭）；小巧思沿用 `ab695962-b420-4731-b14c-3f6860909fd9`，只换正文与显示名称，保留其原开关。条目均沿用原system角色和相对排序位置。
