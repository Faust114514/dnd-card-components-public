# DND 角色卡组件

当前版本 **vf.0.3.3**。这是公开下载用的源码仓库，由当前组件文件重新建立，不包含原私库的提交历史。

只收录11个助手脚本、16个界面/正则源码及配置、说明和测试。完整角色卡PNG/JSON、世界书、预设、聊天、人物存档和访问令牌不上传。现有上游依赖及素材权利归属保持原样；公开下载不代表这些内容被重新授予开源许可。

## 使用

支持 **vf.0.2.21** 和 **vf.0.3.x**。首次从旧的私有更新路线切换时，导入本地交付的“组件更新（公开下载）.json”，替换同ID旧脚本，不保留重复项。

为保留已安装脚本的按钮配置，助手入口仍叫“私有更新”；它打开的新版窗口显示“公开下载 · 无需登录或令牌”。悬浮骰子中的入口改为“组件更新”。点击“检查更新”，确认版本说明后选择“安装并刷新页面”。

更新器从本仓库的公开原始文件地址下载，无需GitHub账号、令牌或授权。只发送GET下载请求，不上传卡或聊天。每次安装仍由用户点击确认，打开聊天不会自行下载或安装。

vf.0.2.21会补入缺少的悬浮脚本并更新DM代码。其他更早的.2版本尚未适配。原卡的世界书、人物、聊天、整卡号和世界书名称均保留，在线版本记在独立的组件版本字段中；无需换整卡或另开聊天。

更新会覆盖指定ID的脚本content、正则replaceString，保留原开关、顺序、配置、未知字段和自行添加的组件。自行修改过这些源码时，修改会被发布版本覆盖。

## 维护与发布

- `src/scripts/`：助手脚本源码。
- `src/regexes/`：正则替换文本及HTML，保留原包装和素材。
- `components.json`：组件ID、原生配置和源文件对应关系。
- `latest.json`：当前版本、说明及下载文件列表；不含卡或存档。
- `tools/check_source.py`：源码语法、映射和上传范围检查。
- `tests/updater.cjs`：核心合并与独立Edge模拟宿主检查。

维护源码后同步两份JSON中的版本号，运行 `python tools/check_source.py` 及 `node tests/updater.cjs`。旧卡界面路径另加 `--legacy`；可选的vf.0.2.21文件参数仅在本机读取，不复制进仓库。

提交前确认作者邮箱使用GitHub的隐藏邮箱地址。本仓库不要合并原私库历史，也不要把整卡和本地交付目录放进来。

发布时创建与版本一致的新标签，将main与标签一起推送。清单从main读取，组件源码按固定版本标签下载；不要移动已经发布的标签。保留清单中的 `legacy_card_versions` 以支持已接入的vf.0.2.21卡。

## 验证边界

原生保存接口依据本地SillyTavern1.18.0源码、助手按钮依据4.12.0核对。采用原始扩展字段，保留助手规范化正则接口可能丢弃的substituteRegex和未知字段。

自动测试使用真实Edge、模拟酒馆与下载接口；页面刷新用计数器代替。真实SillyTavern/TauriTavern的导入、保存及刷新后启动仍需实际试用。公开下载也需要设备能够连接GitHub原始文件域名。
