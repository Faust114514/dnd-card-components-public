# DND 角色卡组件

当前版本 **vf.0.3.13**。这是公开下载用的源码仓库，由当前组件文件重新建立，不包含原私库的提交历史。

收录11个助手脚本、18个界面/正则源码、随卡规则五条、一条新增预设提示及配置、说明和测试。完整角色卡PNG/JSON、完整世界书、完整预设、私人模组、聊天、人物存档和访问令牌留在本地。现有上游依赖及素材权利归属保持原样；公开下载不代表这些内容被重新授予开源许可。

## 使用

vf.0.3.13 将原世界书 UID12“玩模组打开”改为支持 EJS 按存档提供资料的主持规则：保留自由探索和玩家决定，沿用消息层 `stat_data` 与原 MVU 更新，不再要求强制线性推进、虚构搜索工具或为剧情保护敌人。没有新增引擎、开关、预设或存档迁移。

旧聊天将 [EJS模组主持规则](src/worldbook/EJS模组主持规则.txt) 正文复制到原书 UID12，保留原条目设置；也提供 [单条导出](src/worldbook/EJS模组主持-世界书单条.json) 供核对。不要另加一个同名常开条目，也不要替换整本世界书。**现有在线更新器仍只更新原来的三条规则，不会自动替换 UID12。** 需要 EJS 的独立模组另行在本地导入并关联到聊天，启用 ST-Prompt-Template 和现有“玩模组”开关。普通纯文本模组可继续使用；不使用 EJS 模组时无需新增扩展。

模板接口按本机 ST-Prompt-Template 1.17.9 源码核对。本地第一层试作使用该扩展自带 EJS 引擎完成 100 个离线场景检查；这不等于真实酒馆的扫描、保存或模型行为已验证。私人模组正文及测试材料不在本公开仓库。

vf.0.3.12 为现有战斗地图补充地图范围、底面与地形。模型在原有 `battle` 区块中声明 `map` 范围、底面和 `terrain` 地形，再输出原单位行。支持矩形、椭圆和多边形，包含墙、水、杂物、植物、高台、阶梯及高度/通行说明。范围由模型结合场景确定，扩展时保留已有坐标；越界会提示，不替模型裁定。没有新泡泡开关、地图变量、独立战斗系统或副 API。

旧聊天先使用现有更新器更新组件并刷新，再把 [战场生成单条世界书](src/worldbook/战场生成-世界书单条.json) 合并到原书（UID 781429），并把 [战场规划](src/prompts/战场规划.txt) 添加为启用的 system 预设段落，放在现有战斗检查前。这两条提示**不会由更新器自动添加**；本次保留原更新器和预设联动逻辑。单条世界书不要替换整本旧书，完整预设有个人修改时只添加该提示。

每条战斗回复都输出完整场地图面；战斗结束停止输出整个 `battle`，旧楼层保留历史显示，发送前沿用旧地图清理规则。旧的纯单位格式仍可用，规则判定与人物 MVU 更新保持原样。`node tests/battle-terrain.cjs <截图目录>` 在隔离 Edge 检查实际渲染、跨轮更新、范围、旧格式、拖动缩放与390px页面；不代表真实酒馆或实际模型效果已验收。

vf.0.3.11 修复“规则更新记录保存不完整”的误报。宿主保存时可能重排 JSON 对象字段；旧更新器把相同内容的不同排列判为失败。现在逐项比较书名、版本及保留记录，仍拦截真正的缺项或内容不一致。保留完整传记功能及所有现有规则。旧更新器首次安装此版仍可能显示同一旧提示：若提示恰为“已提交保存，但复核未完成：规则更新记录保存不完整”，请手动刷新页面，让已保存的新版更新器启动，再检查一次。其他保存或下载错误不要按此提示判断成功。无需重导整卡或替换旧聊天世界书。

vf.0.3.10 在创建页第一项基础设定中加入完整传记，含原有性别共15项。允许先填写职业、属性、专长等选项，最终创建时才检查人设空项；不限字数。填写内容进入状态栏原有传记栏目，玩家名仍存于原有界面设置。修复个性文字重新读取后全部挤进一栏，以及外貌修改被旧档案覆盖的问题；保留分号、换行与原样文本。已有聊天使用公开更新器更新组件并刷新，无需替换世界书。离线及隔离浏览器验证不代替真实酒馆验收。

vf.0.3.9 为创建页种族、背景、专长及升级专长入口添加可输入筛选的下拉框。名称显示中文和英文，仅原文有先决条件时附加括号，条件不参与搜索；支持滚动、键盘和窄屏。普通下拉框和搜索框在各自页面共用原有表单样式，统一高度、底色、边框、字号及箭头。只改变显示与查找方式，保留原选择值、规则判断和存档结构。低于 vf.0.3.9 的公开更新器检查并安装后刷新即可，旧聊天无需替换世界书。本次按用户要求保持 vf.0.3.9 并修正空条件显示与选择框样式：已安装先前 vf.0.3.9 的用户，更新器会跳过同版本组件，须使用本地交付的两份局部正则替换创建和升级界面。

同版本再次修正外置费伦资料的读取：部分宿主会把缺失的文本请求返回为状态码200的HTML页面，旧解析器会把网页标签误当成背景和专长名称。现在按响应类型和文档开头拒绝HTML，保留内置资料及正常文本/JSON。若已安装上一轮样式修正版，本次只需替换创建页局部正则；版本仍为vf.0.3.9。

vf.0.3.8 接入本地 vf.0.3.7 的功能整合，并更新当前卡绑定世界书的三条骰子和检定规则。旧更新器首次安装刷新后，再检查并安装一次“补齐世界书与规则设置”。世界书中手动改过的正文会显示当前与新版内容，选择保留或覆盖后才能安装。世界书名称、条目设置及其他条目保留。

vf.0.3.6 把隐藏规则用到的空替换文本直接记在清单的 `empty_regexes` 中。旧更新器只下载其余 22 个文件，新更新器直接把这 5 条规则的替换文本设为空串。若其他下载失败，窗口会显示状态码和文件路径。

同一条回复可生成多个人物面板，各自编辑、保存。使用 vf.0.3.4 更新器时，首次安装后页面会刷新。再次点击“检查更新”，看到“补齐人物显示规则”时再点一次安装。第二次会补齐世界书、两条新增正则和显示／发送设置。已自定义的匹配表达式沿用个人设置。

支持 **vf.0.2.21** 和 **vf.0.3.x**。首次从旧的私有更新路线切换时，先停用旧更新器，再导入本地交付的“组件更新（公开下载）.json”并启用；只启用一个更新器。助手导入会重新分配ID，不会按导出文件的ID替换旧条目。

为保留已安装脚本的按钮配置，助手入口仍叫“私有更新”；它打开的新版窗口显示“公开下载 · 无需登录或令牌”。悬浮骰子中的入口改为“组件更新”。点击“检查更新”，确认版本说明后选择“安装并刷新页面”。

更新器从本仓库的公开原始文件地址下载，无需GitHub账号、令牌或授权。只发送GET下载请求，不上传卡或聊天。每次安装仍由用户点击确认，打开聊天不会自行下载或安装。

vf.0.2.21会补入缺少的悬浮脚本并更新DM代码。其他更早的.2版本尚未适配。在线安装沿用当前卡的世界书绑定和整卡号，版本记录包含组件和本次世界书处理结果。选择保留的个人规则会记录到本次版本。

更新会覆盖指定ID的脚本content、正则replaceString，保留原开关、顺序、配置、未知字段和自行添加的组件。自行修改过这些源码时，修改会被发布版本覆盖。

vf.0.3.4修复了导入后的自检失败：助手4.12.0会重建脚本ID，更新器现在使用脚本iframe内的 `getScriptId()` 定位自身。其余组件仍按既定ID匹配，不按名称猜测，也不改写导入后的ID。旧版若已卡在“组件缺失或重复：私有组件更新”，需手动导入本地修复版一次。

## 维护与发布

- `src/scripts/`：助手脚本源码。
- `src/regexes/`：正则替换文本及HTML，保留原包装和素材。
- `components.json`：组件ID、原生配置和源文件对应关系。
- `latest.json` 为当前版本、说明及下载文件列表，另列新增正则和世界书更新文件。
- `src/worldbook/updates.json` 保存三条规则的旧正文及新版正文，用于发现个人修改。
- `tools/check_source.py`：源码语法、映射和上传范围检查。
- `tests/updater.cjs`：核心合并与独立Edge模拟宿主检查。
- `tests/biography.cjs`：创建、状态栏、升级页的人设文字往返与旧数据保留检查。
- `tests/faerun-data.cjs`：外置费伦文本误返HTML及正常文本/JSON的回归检查，运行 `node tests/faerun-data.cjs`。

维护源码后同步两份JSON中的版本号，运行 `python tools/check_source.py` 及 `node tests/updater.cjs`。本次世界书记录回归运行 `node tests/updater.cjs --worldbook`，覆盖保存后的字段重排、五类实际记录缺失/不一致及个人修改保留。旧卡界面路径另加 `--legacy`；可选的vf.0.2.21文件参数仅在本机读取，不复制进仓库。

每次更新完成相关验证后，都要同步源码、清单、版本标签并推送，供卡内下载。提交前确认作者邮箱使用GitHub的隐藏邮箱地址。本仓库不要合并原私库历史，也不要把整卡和本地交付目录放进来。

发布时创建与版本一致的新标签，将main与标签一起推送。清单从main读取，组件源码按固定版本标签下载；通常不要移动已经发布的标签。本次经用户明确要求保持 vf.0.3.9，修正提交会同步该标签；返工前的提交仍保留在 main 历史中。保留清单中的 `legacy_card_versions` 以支持已接入的vf.0.2.21卡。

## 验证边界

原生保存接口依据本地SillyTavern1.18.0源码、助手按钮与世界书绑定接口依据4.12.0核对。世界书读取与即时保存使用宿主的 loadWorldInfo/saveWorldInfo，更新后用原生读取接口复核，成功后才记录组件版本；部分保存失败可重新检查后补齐。采用原始扩展字段，保留助手规范化正则接口可能丢弃的substituteRegex和未知字段。

自动测试使用真实Edge、模拟酒馆与下载接口；页面刷新用计数器代替。真实SillyTavern/TauriTavern的导入、保存及刷新后启动仍需实际试用。公开下载也需要设备能够连接GitHub原始文件域名。
